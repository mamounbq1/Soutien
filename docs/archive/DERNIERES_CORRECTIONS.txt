  🔴 ERREUR 6: AttributeError TEXT_SECONDARY
───────────────────────────────────────────────────────────────────────

**Erreur Complète:**
```
File "ui/payments.py", line 351, in _create_payment_row
    {"text": payment[5][:10], "font_size": 10, "fg": ModernTheme.TEXT_SECONDARY},
                                                     ^^^^^^^^^^^^^^^^^^^^^^^^^^
AttributeError: type object 'ModernTheme' has no attribute 'TEXT_SECONDARY'
```

**Cause:**
- Fichiers `ui/payments.py` et `ui/groups.py` utilisent `ModernTheme.TEXT_SECONDARY`
- Mais seuls `TEXT_SECONDARY_LIGHT` et `TEXT_SECONDARY_DARK` existaient
- Pas d'alias pour le mode par défaut

**Solution Appliquée:**
Ajout de 3 alias dans `config/theme.py`:

```python
# Alias pour compatibilité (mode par défaut = light)
TEXT_PRIMARY = TEXT_PRIMARY_LIGHT
TEXT_SECONDARY = TEXT_SECONDARY_LIGHT
TEXT_DISABLED = TEXT_DISABLED_LIGHT
```

**Résultat:**
✅ TEXT_PRIMARY: #1A1D23
✅ TEXT_SECONDARY: #5F6368
✅ TEXT_DISABLED: #9E9E9E
